# Tutorial

처음이라면 여기서 시작합니다. 두 가지 경로가 있습니다:

| 경로 | 소요 | 다루는 범위 | 추천 대상 |
|---|---|---|---|
| [**Quick Start (5 분)**](quick-start.md) | 5 분 | 설치 → 첫 project → 첫 plan, 3 명령 | "이게 뭔지 모양만 보고 싶다" |
| **Deep Walkthrough (30 분)** | 30 분 | 11 단계 전체 — init wizard, analyze, TDD 모드 활성화, 첫 evaluator 까지 | "실제 프로젝트에 도입하려고 한다" |

!!! note "Deep Walkthrough 는 작성 중"
    현재는 `pilot/docs/getting-started.md` 의 내용을 이전하는 중입니다. v0.5.0 에 사이트로 합쳐집니다.

## 어디로 가야 할까

- **pilot 을 처음 들었다면** → Quick Start 부터.
- **이미 plugin 을 설치했고 첫 프로젝트를 시작하려 한다면** → Quick Start 의 step 2 (`/pilot:project`) 로 바로.
- **개념·아키텍처를 먼저 이해하고 싶다면** → [Explanation](../explanation/index.md) (단, 처음 사용자에게 권장하지는 않습니다 — 한 사이클 직접 돌려보는 게 빠릅니다).
