# Issues - 운영 이슈 작성 가이드

## 개요

운영 환경에서 발생하는 이슈를 진단하고 해결하기 위한 가이드.
**프로젝트 모드와의 차이:** 현재 수정 중인 파일이나 프로젝트 컨텍스트를 참조하지 않는다. 이슈의 기본 조건과 문제점 파악에 집중한다.

## 동작 방식

| 사용법        | 동작                                                                                           |
| ------------- | ---------------------------------------------------------------------------------------------- |
| `/pilot:issue`          | 이슈 모드 활성화. 가이드만 로드하고 바로 이슈 처리 시작.                                       |
| `/pilot:issue {이슈명}` | `workspace/issues/{이슈명}/` 폴더 생성 후 이슈 컨텍스트 로드. 원인·조치를 기록으로 남긴다. |

## 운영 이슈 처리 원칙

1. **현상 재현** — 이슈 발생 조건을 정확히 파악한다
2. **영향 범위 확인** — 어떤 사용자/데이터에 영향을 미치는지 확인한다
3. **원인 분석** — SCOPE, ENUMS, RULES를 참조하여 근본 원인을 추적한다
4. **최소 변경** — 운영 안정성을 위해 변경 범위를 최소화한다
5. **롤백 가능** — 수정 사항은 항상 롤백 가능하도록 설계한다

## 이슈 진단 절차

```text
1. 기존 이슈 검색 → workspace/issues/ 폴더에서 유사 이슈 확인
   ├─ 있으면 → 해당 내용 참조 후 회신
   └─ 없으면 → 아래 절차 진행

2. 현상 확인 → 에러 로그, 재현 조건 파악
3. 관련 코드 탐색 → scope.md 기반으로 라우트/모델/서비스 특정
4. 상태 확인 → enums.md로 현재 상태값과 전이 방향 검증
5. 규칙 대조 → rules.md로 비즈니스 규칙 위반 여부 확인
6. 수정 → 최소 범위로 코드 또는 데이터 수정
7. 검증 → 수정 후 정상 동작 확인
```

## 이슈 폴더 구조

`/pilot:issue {이슈명}` 사용 시 아래 구조로 생성한다.

```text
workspace/issues/{이슈명}/
└── issue.md     # 현상, 원인, 조치 내용 (필수)
```

## issue.md 작성 워크플로우

```text
1. 사용자 → 현상 작성 (증상, 에러, 재현 경로)
2. AI     → 코드 분석 → 원인 섹션 자동 기입
3. AI     → 필요 시 → 조치 섹션 자동 기입
4. AI     → 필요 시 → 재발 방지 섹션 자동 기입
```

### 섹션별 역할

| 섹션      | 작성 주체     | 시점         |
| --------- | ------------- | ------------ |
| 현상      | 사용자        | 이슈 등록 시 |
| 의심 영역 | 사용자 (선택) | 이슈 등록 시 |
| 원인      | AI            | 분석 완료 후 |
| 조치      | AI (선택)     | 수정 완료 후 |
| 재발 방지 | AI (선택)     | 조치 완료 후 |

### 섹션 설명

- **현상** — 증상, 에러 메시지, 재현 경로
- **의심 영역** — 문제가 예측되는 라우트, 모델, 서비스 등. AI 탐색 범위를 좁힌다.
- **원인** — 근본 원인과 영향 범위
- **조치** — 소스 변경, DB 변경(쿼리) 등 수정 내용
- **재발 방지** — 동일 이슈 재발 방지 조치

## issue.md 템플릿

```markdown
# {이슈명}

## 현상

- {어떤 증상이 발생하는지}
- {에러 메시지 또는 비정상 동작}
- {재현 경로}

## 의심 영역

- {라우트, 모델, 서비스 등 예측되는 문제 지점}

## 원인

_(분석 후 자동 기입)_

## 조치

_(수정 완료 후 자동 기입)_

## 재발 방지

_(필요 시 자동 기입)_
```
